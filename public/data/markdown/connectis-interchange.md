# Validação de taxas de intercâmbio — Banco do Brasil

## Contexto

Analista de Sistemas Sênior na Connectis, no projeto de validação das taxas de intercâmbio das bandeiras (Visa, Mastercard, Elo), entre 10/2019 e 11/2020.

## O que este trabalho demonstra

### Migração de sistema crítico
- migração da análise de intercâmbio do mainframe COBOL para a plataforma moderna do banco, preservando precisão e confiabilidade;
- arquitetura híbrida: Java Quarkus e Spring Batch para grandes volumes, mais APIs em COBOL online seguindo o padrão do banco, o que permitiu transição gradual.

### Frontend e infraestrutura
- telas em Angular 8 integradas aos serviços modernos e aos serviços COBOL online;
- contêineres com Docker e Kubernetes, CI/CD no Jenkins e Elasticsearch para monitoramento e relatórios.

## Aprendizado

Em sistema financeiro, compatibilidade e precisão pesam tanto quanto a modernização: a melhor migração é a que dá para fazer por etapas.

## Stack

Java, Quarkus, Spring Batch, COBOL, Angular 8, Docker, Kubernetes, Jenkins, Elasticsearch.
