# Natura Pay e Natura FVN

## Contexto

Desenvolvimento de dois produtos da Natura & Co entre 04/2021 e 12/2021, em um projeto híbrido de iOS nativo com React Native.

## O que este trabalho demonstra

### Integração nativo + React Native
- iOS Native Modules fazendo a ponte entre o código Swift e a interface em React Native, mantendo desempenho nativo onde importa;
- interface programática (ViewCode) nas partes nativas.

### Backend e nuvem
- backend em Node.js e TypeScript na AWS, com Elasticsearch para busca;
- CI/CD com GitHub Actions.

## Stack

Swift, React Native, iOS Native Modules, ViewCode, Node.js, TypeScript, AWS, Elasticsearch, GitHub Actions.
